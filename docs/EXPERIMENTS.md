# Sequential panel experiment

The primary block search partitions 315 coordinates into six regional spectral blocks (21 each), three connectivity-band blocks (45 each), and three strength-band blocks (18 each). EO/EC/contrast coordinates stay together inside each block. Static-band and full-feature searches are optional separately prespecified analyses, not alternative results to cherry-pick after testing.

Within every outer leave-one-release-out training set, a three-fold stratified family-group CV scores each possible next addition. Median imputation and RF training are repeated per candidate and inner training fold. The complete forward path runs to the configured maximum; a one-standard-error heuristic chooses the smallest eligible panel. The standard error uses correlated inner fold scores and is not a formal uncertainty guarantee. The algorithm is greedy and cannot prove global optimality or recover every synergistic pair.

The selected panel is compared against the first selected step and all candidates, using identical outer participants and fixed RF settings. The reference uses 200 trees, balanced class weighting, minimum leaf size 3, unlimited depth and seed 2026. Repeat separately fixed seeds to assess sensitivity; do not select a favorable seed. Models fit on the outer training set are saved with their exact column lists.

The primary outcome is the paired selected-minus-all-candidates change in outer balanced accuracy, interpreted with the number of features. Selection identity stability is descriptive across four overlapping outer training sets. Co-selection is not connectivity or interaction; conditional gains are adaptive inner-development statistics. Outer performance is not used to pick the winning search step.

Outputs include selected_panels.json, selection_paths.json, candidate_evaluations.json, splits.json, oof_predictions.csv, metrics.csv, paired_comparisons.json, model files, and six PDF/PNG visualization families. Feature-frequency and Jaccard CSVs are generated by the plotting command.

This project does not provide an all-data deployment refit, a full nested permutation significance test, demographic-only/adjusted modeling, or external validation. These are follow-up studies; the current manuscript does not claim them as completed. The shared feature extractor is consistent with Repo3, so one audited feature CSV can be reused.
